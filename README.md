# ClearView Client (Fabric, Minecraft 1.21.11)

Features
- FPS Boost (F8): lowers render/sim distance, minimal particles, fast graphics, no clouds/shadows, uncapped FPS. Restores your settings when turned off.
- Swing animations: Vanilla, Smooth, Slide, Stab, Spin, Swirl, Chop (+ swing size, no equip dip)
- Small held items: item size % and X/Y/Z offsets
- Custom main menu: Aurora, Minimal, Classic
- Custom totems: Options > Resource Packs > "ClearView Totem: ..." (move one to the selected side)
- FPS counter (F9)

Settings screen: RIGHT SHIFT in game, or the "ClearView" button on the main menu.
Settings are saved in .minecraft/config/clearview.json

Build: push to GitHub, open Actions, download the "clearview-client-jar" artifact.
